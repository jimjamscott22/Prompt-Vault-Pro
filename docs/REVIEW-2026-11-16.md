## Remaining

### Decision needed first

- [ ] **D1. Auth and serving model (M–L).** Today there is no authentication and no
  single-process production mode. The docs say "localhost only, run two dev servers".
  Either:
  - **Keep as is**, and consider binding the server to `127.0.0.1` explicitly; or
  - **Wire up auth** (register `APIKeyMiddleware` from `backend/auth.py`) and **serve
    `frontend/dist/`** from the backend, adding CORS for the served origin.

  If auth is kept, fix `backend/auth.py` first: it reads the TOML file on every request,
  raises `HTTPException` inside `BaseHTTPMiddleware` (return a `JSONResponse` instead),
  compares keys with `!=` (use `secrets.compare_digest`), and defaults to `local_only = True`.
  The backend does not currently read `config.toml` at all (only the CLI does). After the
  decision, update README, CLAUDE.md, `docs/api.md`, and `docs/architecture.md`.

### Backend

> B1, B3, B4, B5, and B6 are done (uncommitted at the time of writing); their entries
> below are kept for reference. `aiomysql` is now the optional `mysql` extra.

- [x] ✅ **B1. Validate pagination (S).** `page=0` gives a negative offset and `per_page=100000`
  is accepted on all list endpoints (`routers/entries.py`, `bundles.py`, `projects.py`,
  `search.py`). Use `Query(1, ge=1)` and `Query(20, ge=1, le=100)`.
- [ ] **B2. Search pagination happens in Python (S–M).** `services/search_service.py` loads every
  matching row and slices the list. Push filtering and paging into SQL.
- [x] ✅ **B3. Validate `project_id` (S).** Creating or updating an entry with a nonexistent
  `project_id` returns success. Check it in `services/entry_service.py` and return 404/422.
  Also consider `PRAGMA foreign_keys=ON` for SQLite (not enabled today).
- [x] ✅ **B4. LIKE fallback does not escape `%` and `_` (S).** In `_like_search`.
- [x] ✅ **B5. Ruff findings (S).** Run `uv run ruff check backend/ --fix`, then clean up the rest
  (mostly long lines, import order, unused imports).
- [x] ✅ **B6. Dependencies (S).** `pydantic-settings` is declared but never imported. `aiomysql` is
  a hard dependency even though SQLite is the default (make it an optional extra).
- [ ] **B7. MariaDB mode (M).** `database.py` has an optional MariaDB/MySQL mode chosen at import
  time. It has no tests and conflicts with the "SQLite only" rule in CLAUDE.md. Either test and
  document it, or remove it.
- [ ] **B8. Modernize models (M).** Models use legacy `Column(...)`; CLAUDE.md asks for SQLAlchemy
  2.x style (`Mapped[]` / `mapped_column`).
- [ ] **B9. `schema_version` table is created but never written (S).** Either record versions or
  drop it, and update `docs/architecture.md`.

### CLI

- [ ] **C1. Truncated IDs (S–M).** `pv search` and `pv bundle list` show only 8 characters of the
  ID, but `pv bundle add`, `pv export --bundle`, and `pv add --project` need the full ID. Show
  full IDs, or accept unique prefixes, or resolve bundles and projects by name or slug.
- [ ] **C2. Packaging (S).** The CLI installs top-level modules named `main` and `config`
  (`cli/pyproject.toml`), which can collide with other packages. Move them under a package
  (for example `promptvault_cli`). The `tomllib>=2.0.1; python_version < '3.11'` dependency and
  the `tomli` fallback in `cli/config.py` are dead (requires-python is `>=3.11`).
- [ ] **C3. No `pv context` command (M).** CLAUDE.md used to describe project auto-detection from
  the current directory. It was removed from the docs because it does not exist. Build it, or
  leave it out.

### Frontend

- [ ] **F1. Possible bug: cannot create the first folder (S).** `SidebarFolderList` in
  `frontend/src/App.tsx` returns `null` when there are no projects and `isCreating` is false,
  and the only buttons that set `isCreating` are inside that hidden section. **Not confirmed in
  a browser.** Reproduce with an empty database first.
- [ ] **F2. ESLint (S–M).** There is no config, so `npm run lint` fails. `eslint@8` is end of life;
  add a flat config (ESLint 9+) with the React hooks rules.
- [ ] **F3. No pagination UI (M).** The backend defaults to 20 entries per page and the frontend
  does not request more or page through results (no `page`/`per_page` handling in
  `api/entries.ts`, `hooks/useEntries.ts`, or `pages/EntriesPage.tsx`), so entries beyond the
  first 20 appear to be invisible. Verify with 21+ entries.
- [ ] **F4. Data hooks (S–M).** `hooks/useEntries.ts` and `hooks/useProjects.ts` have no error
  state (a failed fetch rejects unhandled) and no abort handling for stale responses.
  `useEntries` depends on `JSON.stringify(params)`. `useSharedEntries` and `useSharedProjects`
  in `App.tsx` are the same hook.
- [ ] **F5. Accessibility (M).**
  - A `<button>` is nested inside a `<button>` in the Folders header (invalid HTML).
  - The sidebar toggle has only `title`; add `aria-label` and `aria-expanded`.
  - `EntryForm` is a modal without `role="dialog"`, `aria-modal`, focus trapping, or Esc
    handling (`ImportModal` is closer). A native `<dialog>` with `showModal()` gives focus
    trapping and Esc for free. Run the `modern-web-guidance` skill before building it.
  - Delete uses `window.confirm`.
  - A collapsed sidebar is hidden with `opacity: 0`, so it stays focusable and readable by
    screen readers.
  - Muted text `#4f5569` on `#0b0d12` is roughly 2.5:1, below WCAG AA for body text.
- [ ] **F6. Split `App.tsx` (L).** About 1,100 lines, mostly inline `style={{…}}` objects and
  `onMouseEnter`/`onMouseLeave` style mutation. CLAUDE.md says design tokens live in
  `index.css`. Extract `Sidebar`, `SidebarFolderList`, `SidebarEntryList`, move styles to CSS
  with `:hover` and `:focus-visible`. Keep the design rules in CLAUDE.md's "Frontend UI Design
  System" section.
- [ ] **F7. Fonts and page metadata (S).** Google Fonts loads through a CSS `@import` in
  `index.css`, which blocks rendering. Use `<link rel="preconnect">` plus `<link>` in
  `index.html`, or self-host (better for a local-first app). Add a meta description and theme
  color.
- [ ] **F8. Dependencies (S).** Run `npm audit fix` (Vite 7.3.2 to 7.3.x clears the in-range
  advisories). Major upgrades available but optional: React 19, react-router 7, Tailwind 4,
  ESLint 10, Vite 8.
- [ ] **F9. Tailwind is installed but barely used (S).** The UI is styled with CSS variables and
  inline styles. Remove Tailwind, or start using it; CLAUDE.md currently notes the mismatch.
